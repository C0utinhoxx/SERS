# Checkpoint 01 — Análise de Dados de Energia Final (SVG)

##  Sobre o Desafio
Este repositório contém a resolução do desafio da disciplina de Soluções em Energias Renováveis e Sustentáveis do curso de Ciência da Computação.

### Situação-Problema
A equipe de planejamento energético precisa analisar o comportamento da carga elétrica de uma região atendida pelo Sistema Interligado Nacional (SIN).

Os dados são obtidos diretamente da API pública do Operador Nacional do Sistema Elétrico (ONS). A conexão com a API e a preparação inicial do JSON. A partir desses dados, o notebook contempla:
* Construção e organização do DataFrame
* Criação de recortes e tratamento de dados
* Cálculo de indicadores energéticos
* Geração de gráficos explicativos
* Elaboração do relatório técnico final

## Fonte dos Dados
* **API:** Carga Verificada do ONS
* **Portal Principal:** [dados.ons.org.br](https://dados.ons.org.br/)
* **Conjunto de Dados:** [Carga de Energia Verificada](https://dados.ons.org.br/dataset/carga-energia-verificada)
* **Dicionário de Dados:** Carga Verificada do ONS
